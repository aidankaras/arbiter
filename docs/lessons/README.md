# Concept notes

One note per concept, written as the corresponding subsystem is built.

Each note covers what the concept is, why it was chosen here, what was
considered and rejected, which code in this repository implements it, and the
questions a reviewer would reasonably ask about it.

These exist because a design decision that cannot be explained is a design
decision that was not made. Writing the note is part of building the thing.
